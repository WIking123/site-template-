# Шаблон сайта для заказчика

Простой сайт на HTML, CSS и JavaScript: без сборки, открывается двойным кликом по `index.html`, публикуется на любом хостинге.

## Как начать сайт для нового заказчика

1. На странице этого репозитория нажмите **Use this template → Create a new repository**.
2. Назовите репозиторий по заказчику, например `client-01-pizzeria-roma`, выберите **Private**.
3. В новом репозитории заполните `CLAUDE.md` (анкета заказчика).
4. Откройте новую сессию Claude Code, выберите **только этот репозиторий** и напишите, например:
   «Прочитай CLAUDE.md и сделай сайт по анкете».
5. Подключите репозиторий к хостингу (Vercel, Netlify или Cloudflare Pages) как отдельный проект со своим доменом.

## Структура

| Файл | Что внутри |
|---|---|
| `CLAUDE.md` | Анкета заказчика и правила для Claude |
| `index.html` | Главная страница: шапка, первый экран, услуги, о нас, контакты |
| `css/style.css` | Стили. Цвета и шрифты заказчика в блоке `:root` в начале файла |
| `js/main.js` | Мобильное меню, текущий год в подвале |
| `images/` | Картинки и логотип |
| `404.html` | Страница «не найдено» |
| `robots.txt` | Настройки для поисковиков |

## Правило

Один заказчик — один репозиторий — отдельная сессия Claude.
